# QLaunch v1.0
Copyright (C) 2004 Cory Nelson

QLaunch is a small launcher for QuakeWorld.  It uses GameStat as it's backend.

## How to use
Edit the variables in qlaunch.conf to your liking.  The server list has one
entry per line, each entry looking like
"server name;server address:port;server password", the password being optional.
